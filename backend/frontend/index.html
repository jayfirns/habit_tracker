    New Goal

    Make it Specific, Measurable, Achievable, Relevant, and Time-bound.

    State the concrete goal in a short phrase (e.g., “Write 500 words before 10am”).

    Describe the routine and constraints so it’s obvious what “doing the goal” looks like.

    Explain how you’ll track success—counts, minutes, sessions per week, or a clear done condition.

    Share why this target is realistic given your current schedule, energy, and constraints.

    Note why this goal matters in plain language—as if explaining it to a friend.

    Set a clear deadline so the dashboard can surface and evaluate this goal on time.
